Youtube adless lite is a lightweight iOS launcher that opens straight into YouTube in a built-in browser and keeps it free of ads — WebKit content-blocking rules, an auto-skip script, and background playback.

What it does

Ad blocking

Content-blocking rules cancel ad and tracking requests; injected CSS and a script hide ad slots and click “Skip” for you.

Minimal toolbar

Just back, home, and a settings badge. YouTube inside the page does the rest.

Background playback

Music and videos keep playing after you leave the app, thanks to the audio background mode.

Picture-in-picture

PiP through YouTube’s own player controls, with YouTube’s inline-forcing behavior neutralized.

Blocked-ad counter

A shield badge in the toolbar counts every ad blocked, and persists across launches.

Desktop or mobile

Serves the mobile layout by default; the desktop site is an opt-in switch in settings.

Install it

The app ships as an unsigned .ipa, so you apply your own signing — nothing is distributed pre-signed.

Build the ipa. Open the Actions tab, run “Build unsigned ipa”, and download the Youtube-Adless-Lite-<version>-ipa artifact. It builds automatically on every push.

Sign it. Use Sideloadly, AltStore, or codesign with your own certificate and provisioning profile.

Install and watch. AirDrop or sync the signed app to your iPhone. Tap the shield badge inside for ad-blocking settings.

Prefer to build it yourself? Clone the repo and run ./make-ipa.sh on any Mac with Xcode — it produces build/Youtube Adless Lite-<version>.ipa.

Build from source

git clone https://github.com/arthurdcosta311-sketch/Tube-Lite.git
cd Tube-Lite
./make-ipa.sh

Requires a Mac with Xcode. The simulator build and the GitHub Actions pipeline build the same project.
